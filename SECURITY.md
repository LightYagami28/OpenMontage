# Security Policy

## Supported Versions

OpenMontage is developed as a single continuous branch. Security fixes are
applied to the tip of `main` in this fork only.

| Version | Supported |
| --- | --- |
| `main` (this fork) | :white_check_mark: |
| Earlier snapshots | :x: |
| Upstream releases | :x: (report through the channel below) |

## Reporting a Vulnerability

Please do **not** open a public issue for a suspected vulnerability. Send the
details through GitHub's private vulnerability reporting for this repository
([Report a vulnerability](https://github.com/LightYagami28/OpenMontage/security/advisories/new)),
including:

- the affected component and the revision you tested;
- steps to reproduce and a proof of concept, if available;
- the impact you observed and any suggested mitigation.

You should receive an acknowledgement within five working days. We will keep
the report private, confirm the finding, prepare a fix on `main` and let you
know when it is safe to disclose. Please give us a reasonable window to fix
the issue before publishing it.

Reports about code inherited from OpenMontageInc/OpenMontage are welcome here:
we will handle the fix in this fork and, where appropriate, pass the details
on to the upstream maintainers through a private channel. Do not open pull
requests against upstream without prior approval.
